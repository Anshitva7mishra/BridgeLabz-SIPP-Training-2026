## 🎯 What is SIPP?

The **Software Immersion Placement Program (SIPP)** by BridgeLabz is an intensive, hands-on fellowship program designed to bridge the gap between academic knowledge and industry expectations.

> _"Not just learning Java — learning how to think like a software engineer."_

### Program Highlights
- 📅 **Duration:** 160 Hours across 35 Days
- 🔢 **Sessions:** 32 Regular Sessions + 3 Workshops
- 💻 **Platform:** CodIn (BridgeLabz's proprietary coding platform)
- 🧩 **Problems:** ~230 Daily Practice Problems + 100+ LeetCode References
- 🛠️ **Focus:** Industry-grade problem-solving, OOP design, and DSA mastery

---

## 🗺️ Learning Roadmap

The program is structured into **3 major stages**, each building on the previous one:

```
Stage 1: Core Java Programming  ──►  Stage 2: OOP with Java  ──►  Stage 3: DSA
   (Days 1–9 | ~45 hrs)                (Days 10–20 | ~55 hrs)       (Days 21–35 | ~60 hrs)
```

## 📚 Stage 1: Core Java Programming
> **Days 1–9 | 8 Sessions + 1 Workshop | ~45 Hours**

Foundations of Java programming — syntax, data types, control flow, arrays, strings, methods, recursion, exception handling, and file I/O.

| Day | Concept | Story Problem | LeetCode Practice |
|-----|---------|---------------|-------------------|
| 1 | Java Environment Setup, JVM/JDK/JRE, Data Types, Variables, Type Casting, Operators, GIT Intro | Ravi joins a coding guild — store his name, age, rank, salary, and membership fee using correct data types. Compute annual bonus (12%) and cast it to `int`. | LC #1 Palindrome Number · LC #2 Roman to Integer · LC #3 Subtract Product and Sum of Digits |
| 2 | Control Flow: if-else, ternary, switch; Loops: for, while, do-while, break, continue | A kingdom's tax system charges 5% for income <10K, 15% for 10K–50K, 30% above 50K. Tally total tax collected across 10 citizens. | LC #4 FizzBuzz · LC #5 Reverse Integer · LC #6 Plus One · LC #7 Number of Steps to Reduce to Zero |
| 3 | Arrays: 1D & 2D, traversal, min/max, linear search, frequency count, rotation | A warehouse manages stock — find max, min, total, and duplicates. Rotate stock array by k positions; transpose a 2D shelf grid. | LC #8 Contains Duplicate · LC #9 Majority Element · LC #10 Max Consecutive Ones · LC #11 Move Zeroes · LC #12 Rotate Array |
| 4 | Strings: String methods, StringBuilder, immutability, palindrome, anagram, character frequency | A spy agency encodes messages — reverse secret messages, detect palindromes, count vowels/consonants, verify anagrams. | LC #13 Valid Palindrome · LC #14 Valid Anagram · LC #15 First Unique Character · LC #16 Reverse String · LC #17 Longest Common Prefix |
| 5 | Functions & Methods: parameters, return types, overloading, pass-by-value, variable scope | Build a 'Math Wizard' utility: `isPrime`, `factorial`, `fibonacci`, `gcd`, `lcm`, `power`. Overload `factorial` for double. | LC #18 Power of Two · LC #19 kth Factor of n · LC #20 Fibonacci Number · LC #21 GCD of Strings |
| 6 | Recursion: base case, recursive case, recursion tree, stack overflow awareness | Solve Tower of Hanoi recursively, count moves. Also implement recursive binary search, sum of digits, string reversal, and balanced parentheses check. | LC #22 Fibonacci Number · LC #23 Climbing Stairs · LC #24 Reverse Linked List (preview) · LC #25 Reverse String |
| 7 | Exception Handling: try-catch-finally, checked vs unchecked, custom exceptions | A hospital billing system must never crash — handle division-by-zero, array out-of-bounds, and number format errors. Create custom `InsufficientFundsException`. | LC #26 Palindrome Number (input validation) · HackerRank Java Exception Handling series |
| 8 | Java I/O: Scanner, BufferedReader, File I/O (FileReader/FileWriter), basic serialization | A school portal reads student names and marks from file, computes averages, and writes a formatted report card to a new file. | LC #27 Find Index of First Occurrence · File I/O design exercise |
| 9 | 🏗️ **WORKSHOP 1: Core Programming Integration** | Build a CLI 'Student Grade Manager' — read data from file, compute grades, sort by marks (bubble sort), write report to output file. Must use methods, exceptions, and file I/O. | LC #28 Merge Sorted Array · LC #29 Pascal's Triangle · LC #30 Plus One · LC #31 Remove Element · LC #32 Move Zeroes |

## 🧩 Stage 2: Object-Oriented Programming with Java
> **Days 10–20 | 10 Sessions + 1 Workshop | ~55 Hours**

Learning the four pillars of OOP — Encapsulation, Abstraction, Inheritance, and Polymorphism — along with Interfaces, Collections, and Generics.

| Day | Concept | Story Problem | LeetCode Practice |
|-----|---------|---------------|-------------------|
| 10 | OOP Fundamentals: Class, Object, Constructor, `this` keyword, static vs instance, access modifiers | Design a `BankAccount` class with deposit, withdraw (with overdraft check), and statement. Track total accounts with a static field. | LC #33 Design Parking System · LC #34 Design HashSet · LC #35 Design HashMap |
| 11 | Encapsulation & Abstraction: getters/setters, data hiding, abstract classes | Build a `Shape` hierarchy — abstract `area()` and `perimeter()`. Concrete: `Circle`, `Rectangle`, `Triangle`. Enforce radius immutability. | LC #36 Design Parking System · LC #37 Min Stack · LC #38 Implement Stack using Queues |
| 12 | Inheritance: `extends`, `super`, constructor chaining, method overriding, `final` | University system: `Person → Student → GradStudent`. Each level adds attributes. Override `toString()` at each level. Make `studentId` final. | LC #39 BST Iterator · LC #40 Flatten Nested List Iterator |
| 13 | Polymorphism: runtime polymorphism, `instanceof`, object casting, dynamic method dispatch | Transport company fleet: `Vehicle[]` with `Car`, `Bus`, `Bike`. Call `fuelCost(km)` — each type calculates differently. Add `ElectricCar` without changing existing code. | LC #41 Design Parking System · LC #42 Encode and Decode Strings |
| 14–15 | Interfaces: interface vs abstract class, multiple implementation, default & static interface methods | Fitness tracker: interfaces `Trackable`, `Reportable`, `Notifiable`. `FitnessDevice` implements all three. Add `resetData()` default method. | LC #43 Implement Queue using Stacks · LC #44 Implement Stack using Queues · LC #45 LRU Cache |
| 16–17 | Collections Framework: `ArrayList`, `LinkedList`, `HashMap`, `HashSet` — CRUD operations and iteration | Address book app with `ArrayList` for ordered storage, `HashMap` for fast name lookup, `HashSet` to prevent duplicate phone numbers. Sort by name. | LC #46 Two Sum · LC #47 Contains Duplicate · LC #48 Intersection of Two Arrays · LC #49 First Unique Character |
| 18–19 | Generics: generic classes, generic methods, bounded type parameters, wildcards | Build a generic `Pair<T, U>`, generic `Stack<T>`, `findMax(T[])` bounded to `Comparable`, and a generic `Repository<T>`. | LC #50 Find Median from Data Stream · LC #51 Flatten Nested List Iterator |
| 20 | 🏗️ **WORKSHOP 2: OOP Design Challenge — Library Management System** | Full LMS using all OOP pillars: `Book` (abstract), `PhysicalBook`, `EBook`; `Member`, `PremiumMember`; interfaces `Borrowable`, `Reservable`. ArrayList + HashMap for storage. | LC #52 LRU Cache · LC #53 LFU Cache · LC #54 Design Parking System · LC #55 Implement Trie · LC #56 Encode Decode Strings |

## 🧠 Stage 3: Data Structures & Algorithms (DSA)
> **Days 21–35 | 14 Sessions + 1 Workshop | ~60 Hours**

From sorting and searching to trees, graphs, and backtracking — developing algorithmic thinking with real-world problem analogies.

| Day | Concept | Story Problem | LeetCode Practice |
|-----|---------|---------------|-------------------|
| 21 | Sorting: Bubble Sort, Selection Sort, Insertion Sort — swap counting, stability, best/worst case | Sort 50 athletes by score using Bubble Sort. Count total swaps and detect already-sorted arrays. Repeat with Insertion Sort. Find top-3 medalists. | LC #57 Sort an Array · LC #58 Sort Colors · LC #59 Largest Number · LC #60 Height Checker |
| 22 | Efficient Sorting: Merge Sort, Quick Sort, Counting Sort — divide-and-conquer, partitioning | A library sorts 1M books by year. Implement Merge Sort (O(n log n)), Quick Sort with Lomuto partition, Counting Sort for bounded categories. Compare empirical runtimes. | LC #61 Sort an Array · LC #62 Count of Smaller Numbers After Self · LC #63 Sort List · LC #64 Reverse Pairs |
| 23 | Binary Search: standard, rotated arrays, first/last occurrence, search on answer | Astronomer with 10M sorted star-brightness entries. Search in O(log n), handle rotated catalog, find first/last occurrence of repeated values. | LC #65 Binary Search · LC #66 Search in Rotated Sorted Array · LC #67 First and Last Position · LC #68 Minimum in Rotated Array · LC #69 Find Peak Element |
| 24 | Two Pointers & Sliding Window: pair sum, triplets, max subarray of length k, variable window | River station records water levels. Find longest contiguous period in range, all unique triplets summing to zero, max average subarray of length k. | LC #70 Container With Most Water · LC #71 3Sum · LC #72 Longest Substring Without Repeating · LC #73 Minimum Window Substring · LC #74 Permutation in String · LC #75 Fruit Into Baskets |
| 25–26 | Linked List: singly & doubly — insert, delete, reverse, cycle detection, merge, find middle | Train management system models coaches as a linked list. Add/remove coaches, reverse the train, detect circular routes, find middle coach, merge two sorted schedules. | LC #76 Reverse Linked List · LC #77 Linked List Cycle · LC #78 Middle of Linked List · LC #79 Merge Two Sorted Lists · LC #80 Remove Nth from End · LC #81 Palindrome Linked List |
| 27 | Stacks: array & linked-list implementation, balanced brackets, next greater element, stock span | Compiler validates balanced brackets `()`, `{}`, `[]`. Compute Next Greater Price for each day (O(n) monotonic stack). Calculate stock span. | LC #82 Valid Parentheses · LC #83 Daily Temperatures · LC #84 Next Greater Element I · LC #85 Largest Rectangle in Histogram · LC #86 Decode String |
| 28 | Queues & Deque: circular queue, deque, priority queue (min-heap), sliding window maximum | Hospital triage processes patients by severity (priority queue). Sliding window max on vitals using monotonic deque. Circular queue for round-robin CPU scheduler. | LC #87 Sliding Window Maximum · LC #88 Last Stone Weight · LC #89 Top K Frequent Elements · LC #90 Kth Largest Element · LC #91 Design Circular Deque |
| 29 | Hashing: HashMap internals, HashSet, collision handling, frequency maps, two-sum variants, subarray sum | Detective agency tracks suspects across cases. Find most investigated suspect, suspects in exactly 2 cases, pairs always seen together. Subarray sum equals target K using prefix sum + HashMap. | LC #92 Two Sum · LC #93 Group Anagrams · LC #94 Longest Consecutive Sequence · LC #95 Subarray Sum Equals K · LC #96 LRU Cache |
| 30 | Trees: Binary Tree traversals (in/pre/post/level), height, diameter, BFS | Family tree app stores ancestors. All 4 traversals (recursive & iterative), height, level-order BFS, diameter, balanced check. | LC #97 Tree Traversals · LC #98 Level Order Traversal · LC #99 Diameter of Binary Tree · LC #100 Balanced Binary Tree · LC #101 Invert Binary Tree · LC #102 Maximum Depth |
| 31 | BST: insert, search, delete (all 3 cases), validation, kth smallest, LCA | Dictionary app stores words for O(log n) lookup. Insert 20 words, search, delete all 3 node cases, find kth alphabetical word, validate BST property, find LCA. | LC #103 Search in BST · LC #104 Validate BST · LC #105 Kth Smallest in BST · LC #106 LCA of BST · LC #107 Delete Node in BST · LC #108 Sorted Array to BST |
| 32 | Heaps: min/max heap, heapify, heap sort, top-K problems | Stock exchange ranks companies by market cap. Build a max-heap from scratch. Use Java's `PriorityQueue` for top-K stocks. Implement heap sort. | LC #109 Kth Largest Element · LC #110 Merge K Sorted Lists · LC #111 Kth Smallest in Sorted Matrix · LC #112 Find Median from Data Stream |
| 33 | Graphs: adjacency list & matrix, BFS shortest path, DFS all paths, connectivity, cycle detection | City navigation app models 10 cities. BFS: shortest path. DFS: all paths from source to destination. Detect connected components and cycles (course prerequisite check). | LC #113 Number of Islands · LC #114 Clone Graph · LC #115 Course Schedule · LC #116 Rotting Oranges · LC #117 Pacific Atlantic Water Flow · LC #118 Surrounded Regions |
| 34 | Recursion & Backtracking: N-Queens, combination sum, permutations, subsets, word search | Chess puzzle generator places N queens on N×N board without conflicts. Generate all permutations of a secret code, all subsets of inventory, combinations summing to target budget. | LC #119 N-Queens · LC #120 Combination Sum · LC #121 Permutations · LC #122 Subsets · LC #123 Word Search · LC #124 Generate Parentheses · LC #125 Combination Sum II |
| 35 | 🏗️ **WORKSHOP 3: Final DSA Assessment on CodIn** | 8 problems — Easy (2), Medium (4), Hard (2) — spanning Arrays, Linked List, Trees, Graphs, DP, and Backtracking. Scoring: correctness + speed. Peer code review + mentor feedback. | LC #126 Trapping Rain Water · LC #127 Largest Rectangle in Histogram · LC #128 Merge K Sorted Lists · LC #129 Binary Tree Max Path Sum · LC #130 Course Schedule · LC #131 Burst Balloons · LC #132 N-Queens · LC #133 Find Median from Data Stream |
